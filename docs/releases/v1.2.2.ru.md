# PGN Spy v1.2.2

PGN Spy — это настольная Windows-программа для анализа шахматных партий в формате PGN с помощью UCI-совместимого движка. Она помогает оценивать согласованность ходов с движком, качество игры и связанные статистические показатели как по одной партии, так и по более крупной подборке партий.

## Основные изменения

- **исправление crash:** анализатор больше не падает при запуске без аргументов (например, `--help`)
- **исправление crash:** безопасная обработка XML-анализа без оценочных данных (пустой `m_avTopMoves`)
- **thread safety:** устранён data race на глобальных переменных состояния движка между основным и мониторным потоком
- **thread safety:** нереентерабельный статический буфер в `getResponse()` заменён на per-instance член
- **утечка ресурсов:** pipe-дескрипторы Windows теперь корректно закрываются в деструкторе Engine
- **утечка ресурсов:** частичное выделение pipe в `LaunchAnalyser` очищается при ошибке
- **безопасность:** устранён риск command injection — пользовательские пути экранируются перед передачей в `CreateProcess`
- **XML:** `find_first_of` заменён на `find` для точного поиска подстроки при экранировании значений
- **новый файл:** `LICENSE` добавлен в корень репозитория для автоопределения GitHub
- **manifest:** версия сборки синхронизирована с `1.2.2.0`
- **чистка кода:** удалены мёртвый код и закомментированные отладочные блоки

## Примечания

- UCI-движок требуется, но не входит в базовый релизный пакет.
- Для этой версии рекомендован и протестирован Stockfish 18.
- Итоговые XML и аннотированный PGN сохраняются рядом с исходным PGN-файлом.

## Быстрый старт

1. Распакуйте zip-архив.
2. Запустите `PGN Spy.exe`.
3. Выберите PGN-файл и UCI-движок.
4. При необходимости задайте число потоков движка и параллельных партий.
5. Запустите анализ и затем откройте XML или аннотированный PGN.
