# PGN Spy v1.2.2

PGN Spy is a Windows desktop application for analyzing chess games in PGN format with a UCI-compatible engine. It helps inspect engine correlation, move quality, and related statistics across a single game or a larger collection.

## Highlights

- **crash fix:** the analyser no longer crashes when run without arguments (e.g., `--help`)
- **crash fix:** safe handling of analysis XML that lacks evaluation data (empty `m_avTopMoves`)
- **thread safety fix:** eliminated data race on engine state globals between main and monitor threads
- **thread safety fix:** replaced non-reentrant static buffer in `getResponse()` with a per-instance member
- **resource leak fix:** pipe handles on Windows are now properly closed in the Engine destructor
- **resource leak fix:** partial pipe allocation in `LaunchAnalyser` is cleaned up on error
- **security fix:** command injection risk mitigated — user-controlled paths are now escaped before being passed to `CreateProcess`
- **XML fix:** `find_first_of` replaced with `find` for exact substring matching in value escaping
- **new file:** `LICENSE` added to the repository root for GitHub auto-detection
- **manifest:** assembly version synced to `1.2.2.0`
- **housekeeping:** dead code and commented-out debug blocks removed

## Notes

- A UCI engine is required but is not bundled in the base release package.
- Stockfish 18 is recommended and tested with this version.
- Final XML and annotated PGN files are saved next to the source PGN.

## Quick Start

1. Extract the zip archive.
2. Run `PGN Spy.exe`.
3. Select a PGN file and a UCI engine.
4. Set engine threads and parallel games if needed.
5. Start the analysis and review the resulting XML or annotated PGN.
