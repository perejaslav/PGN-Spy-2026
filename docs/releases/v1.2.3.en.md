# PGN Spy v1.2.3

A bugfix release. No new features, but analysis is more reliable and the numbers are more accurate.

## Important: statistics

- **An unevaluated move is no longer counted as the best move.** Previously it was counted as a T1 match with 0 CP loss, inflating engine correlation. It is now excluded from statistics.
- **Post-losing positions for Black are now counted correctly.** A missing pair of parentheses let completely lost positions through.

T1 figures may be slightly lower than in v1.2.2. This is expected. Re-analysing old XML files is recommended.

## Reliability

- **A hung engine no longer stalls the analysis.** After ~100 seconds of silence the engine is terminated and the analysis moves on.
- **Analyser errors are now detected.** The exit code used to be ignored.
- **Games are no longer lost because of stderr output.**
- **Tags containing `<` or `>`** (e.g. `U<18`) no longer break the XML.
- Fixed an out-of-bounds read for engines that omit `time`, and a memory leak in the analyser.

## Encoding

- **UTF-8 PGN files are supported.** Non-Latin player names from lichess and chess.com display correctly, and the player filter matches them.
- The input encoding (UTF-8 or ANSI) is detected automatically.
- Annotated PGN is now saved as UTF-8.

## Annotated PGN export

- Games with a `FEN` tag no longer break annotated PGN export for the whole file.

## For developers

- `uci-analyser` builds on Linux with `make` again.
- `pgn-extract` and `uci-analyser` are launched with the program path as argv[0], so the `-s` flag is no longer swallowed.
- Manifest and resource version: `1.2.3.0`.
- `PGN Spy.aps` removed from the repository.

## Package contents

- `PGN Spy.exe`
- `uci-analyser.exe`
- `pgn-extract.exe`
- `README.md`, `README.ru.md`, `ReadMe.txt`, `LICENSE`

A UCI engine is not bundled. Stockfish 18 is recommended.

## Upgrading

Extract the archive over the old folder. Settings are stored in the registry and are kept.
