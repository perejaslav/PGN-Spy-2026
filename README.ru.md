# PGN Spy

PGN Spy — это настольная программа для анализа коллекций шахматных партий в формате PGN с помощью UCI-совместимого движка. Она помогает оценивать согласованность ходов с движком, качество игры и связанные статистические показатели по одной партии или по большой базе партий.

Это современная Windows-сборка исходного проекта. Актуальная линия релизов — `v1.2.3`, в которой добавлены поддержка Windows 11, двуязычный интерфейс English/Russian, экспорт аннотированного PGN и более надёжный рабочий процесс анализа. Релиз исправляет зависания движка, точность статистики, обнаружение ошибок, экспорт аннотированного PGN и имена игроков в UTF-8.

Английская версия: [README.md](README.md)

Рекомендуемый способ получить Windows-сборку — раздел GitHub `Releases`.

## Что делает программа

PGN Spy читает одну партию или коллекцию партий в PGN, преобразует их в формат, который ожидает анализатор, отправляет каждую анализируемую позицию в UCI-движок, например Stockfish, и собирает оценки движка для отчётов.

Программа полезна для:

- сравнения ходов игрока с выбором движка
- построения базовых выборок по сильным шахматистам или турнирам
- разбора сложных позиций с движковой аннотацией
- сохранения результатов как в XML, так и в читаемом PGN

PGN Spy следует использовать как инструмент анализа, а не как самостоятельное доказательство читерства. Результаты нужно сопоставлять с базовыми выборками, размером выборки, контролем времени и другими данными.

## Как это работает

Порядок работы такой:

1. Выберите PGN-файл или коллекцию PGN.
2. Укажите игрока для проверки или оставьте поле пустым, чтобы анализировать все ходы.
3. Настройте движок, глубину книги, число потоков, размер хеша и ограничения поиска.
4. Запустите анализ.
5. PGN Spy подготавливает временные файлы по партиям, запускает `uci-analyser` и взаимодействует с выбранным UCI-движком.
6. Анализатор возвращает оценки движка и сводную информацию.
7. PGN Spy сохраняет результат в XML, а при наличии данных — и в аннотированный PGN с комментариями движка.

В аннотированном PGN используются стандартные комментарии вида `[%eval ...]` после проанализированных ходов.

## Что нужно для запуска

Для работы GUI держите рядом в папке приложения следующие файлы:

- `PGN Spy.exe`
- `uci-analyser.exe`
- `pgn-extract.exe`

Можно использовать любой UCI-совместимый движок. Рекомендуется и протестирован Stockfish.

Исполняемый файл движка может находиться где угодно на диске, потому что PGN Spy сохраняет полный путь к нему в настройках.

## Быстрый старт

1. Запустите `PGN Spy.exe`.
2. Выберите входной PGN-файл.
3. Если нужно анализировать только одного игрока, укажите его имя.
4. Выберите UCI-движок и при необходимости настройте параметры поиска.
5. Запустите анализ.
6. Следите за окном прогресса: там показываются этапы, управление `Pause/Resume/Stop` и состояние партий.
7. После завершения откройте окно результатов, чтобы посмотреть XML-сводку или заново экспортировать аннотированный PGN.

## Файлы результата

PGN Spy может создавать такие файлы:

- XML с результатами анализа для машинной обработки
- аннотированный PGN для ручного просмотра в шахматных программах
- временные PGN в `%TEMP%` во время анализа, которые удаляются автоматически

По умолчанию итоговый XML и аннотированный PGN сохраняются рядом с исходным PGN с именами, содержащими дату и время, чтобы прежние результаты не перезаписывались.

## Выбор языка

Приложение поддерживает английский и русский языки. Используйте переключатель `Language` в главном окне, затем перезапустите программу, чтобы изменение вступило в силу.

## История изменений

По сравнению с исходной версией в `v1.2.1` добавлены:

- поддержка современного поведения UCI-handshake и Stockfish 18
- manifest и DPI-aware интерфейс, рассчитанные на Windows 11
- более аккуратная MFC-верстка с обновлёнными шрифтами и отступами
- управление анализом: `Pause`, `Resume` и `Stop`
- автоматическое сохранение XML и аннотированного PGN
- удобное окно результатов с отображением путей к файлам
- двуязычный интерфейс English/Russian с сохранением выбранного языка
- отдельные настройки для потоков движка и параллельных партий
- гарантированное завершение процессов анализатора и движка при остановке или закрытии

Старые служебные замечания из оригинальной версии сохранены в `ReadMe.txt` для совместимости с существующими файлами установки и ссылками в проектах.
